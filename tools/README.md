# 指南演示（动画）作者工具

指南里那些会动的小棋盘，现在是**纯动画**：**每一帧就是一张画**——画哪几枚棋子、画哪几条箭头、
高亮哪些格子、下面写哪句话、停多久，全部由你写死。游戏只按顺序把这些帧画出来。

```
tools/demos/*.py                     你写这里（棋子 / 箭头 / 高亮 / 文字 / 停留时间）
      ↓  python tools/export_guide_demos.py
neo-two-kings/data/guide_demos.json  游戏读它（别手改）
      ↓  GuideDemos.load_demos() → GuideDemos.build()
帧列表 → GuideDemo 画出来（不跑棋规）
```

> ⚠ **和以前最大的不同**：早先的演示是「每一步拿 `rules.gd` 现算」——改棋规，演示会跟着变，
> 也不可能出现「文字说打得到、画面上却打不到」。
> 现在**不再有这层保护**：画面完全由你摆的样子决定。改棋规之后，请自己回来确认这几段演示还讲得通
> （测试只检查帧数据本身对不对、画不画得出来，不再核对棋规）。

两条路都行：用下面这个可视化编辑器点，或者直接手写 `tools/demos/*.py`。

## 可视化编辑器（推荐）

```bash
python tools/editor/editor.py
```

只用到标准库（tkinter），不用起服务、不用开浏览器。界面四块：

```
┌─ 兵种 王 弓 骑 盾 步   动画 ◀ 第 1/2 段 ▶  新动画 删本段 ─────────────┐
├─ 撤销 重做 重新载入 校验  保存到 Python ─────────────────────────────┤
├──────────┬─────────────────────────────────┬────────────────────────┤
│ 帧        │  工具[摆子|箭头|高亮] 棋子[王弓骑盾步]│  属性                  │
│ 1. 2s …   │              红 绿               │  标题 / 棋盘边长        │
│ 2. 2s …   │  箭头[移动|攻击|跳跃]            │  说明 / 停留时间        │
│ 3. 2s …   │  ┌───────────────────────┐      │  这一帧的箭头（可删）   │
│ +帧 复制帧 │  │        棋盘            │      │                        │
│ 删除 ↑↓   │  └───────────────────────┘      │                        │
├──────────┴─────────────────────────────────┴────────────────────────┤
│ 状态栏：这一步做了什么 / 校验结果                                    │
└─────────────────────────────────────────────────────────────────────┘
```

**工具只有三个**（每一帧是一张画，不需要更多）：

| 工具 | 左键 | 右键 |
|---|---|---|
| `摆子` | 在格子上放当前选的棋子（先在右边选兵种 + 红/绿） | 把那格的棋子擦掉 |
| `箭头` | 点起点、再点终点＝画一条箭头 | 取消这次的起点；没有起点时＝删掉「起点或终点落在这格」的箭头 |
| `高亮` | 切换这一格的橙色高亮 | 同左键（切换） |

其余操作都在左栏与右栏：

* **+帧**：在后面插一帧，**沿用当前帧的棋子与高亮**（通常只差一点），箭头和文字留空重写；
  这也是最顺手的用法——先摆好第一帧，然后一路「+帧 → 改一处 → 写句子」。
* **复制帧**：整帧原样复制（含箭头），用来做「只改一句话」的变体。
* **每帧自己带着全部棋子**（不是增量）：想演「谁没了」，就在下一帧里别写它——盾那段就是这么演的。
* **停留 hold**：这一帧停多久（秒）。以前是「回合时长 + 权重摊分」，现在直接一帧一个数。
* 快捷键：`Ctrl+S` 保存 · `Ctrl+Z` 撤销 · `Ctrl+Y` 重做 · `Ctrl+R` 重新载入（丢掉未保存的改动）· `Del` 擦掉选中格里的棋子。

**保存是安全的**：只重写每个模块里「剧本区」那一段（文件开头的说明与 import 原样保留），
先 `compile()` 一遍生成的源码、再原子写入（写临时文件再替换）；校验不过（比如某帧没写文字）
会直接拒绝保存。

## 一段动画长什么样

```python
Demo(
    caption = "整段动画的标题（画在棋盘下方，不参与动画）",
    size    = 7,                       # 棋盘边长
    frames  = [
        Frame(
            text       = "红王在 (0,0)：这一圈橙色就是王区",
            hold       = 2.0,          # 这一帧停多久（秒）
            pieces     = {(0, 0): red("王"), (1, 1): green("步")},
            highlights = [(0, 0), (1, 0), (0, 1), (1, 1)],
        ),
        Frame(
            text   = "王走上去吃掉它",
            pieces = {(0, 0): red("王"), (1, 1): green("步")},
            arrows = [arrow((0, 0), (1, 1))],
            highlights = [(0, 0)],
        ),
    ],
)
```

坐标写 `(x, y)`：x 向右、y 向下，原点在左上角。

| `Frame` 字段 | 意思 |
|---|---|
| `text` | 棋盘下方那句话（**必填**，空白帧就是观众只看到棋盘在动） |
| `hold` | 这一帧停多久，秒（默认 2.0，必须 > 0） |
| `pieces` | `{(x, y): red("王")}`：这一帧要显示的**全部**棋子（不是增量） |
| `highlights` | 要高亮的格子，比如 `[(0, 0), (1, 0)]` |
| `arrows` | `arrow((0, 0), (1, 1))`，写成列表 |

| `Demo` 字段 | 意思 |
|---|---|
| `caption` | 整段动画的标题 |
| `size` | 棋盘边长（只决定画多大；阵营是每枚棋子自己写明的） |
| `frames` | 一帧一帧往下演 |

⚠ 阵营必须**写明**：`red("王")` / `green("步")`。这里没有棋规能替你推断半场，写清楚了画面上
才是你想要的颜色。当年骑的那两段就踩过这个坑：7×7 上 `(4,2)` 按半场算属绿、`(1,1)` 属红，
照半场画就变成「绿骑跳过两枚红步」，文案里的红骑与绿敌全对不上。

箭头样式三选一（决定颜色）：`arrow((0,0),(1,1))`＝移动（蓝）、
`arrow((0,0),(1,1), "shot")`＝攻击（红）、`arrow((0,0),(1,1), "hop")`＝跳跃（紫）。

## 校验会拦住什么

导出（和编辑器保存）之前逐帧检查，任何一条不过就**一行都不写**：

- 每帧必须有 `text`、`hold > 0`；
- 棋子、高亮、箭头的两端都必须在 `size`×`size` 棋盘内；
- 棋子要写成 `red(...)` / `green(...)`，箭头样式必须是那三种之一；
- 每段动画要有 `caption` 与至少一帧；回合/兵种名不能重复。

另有一条**只提醒不拦**：相邻两帧画面完全一样（只差停留时间）——多半是复制出来忘了改。

## 编辑器自检

```bash
python tools/editor/selftest.py     # 49 项，不写磁盘，退出码 0 = 全通过
```

守的是「编辑器不会把剧本改坏」：磁盘上的模块必须已经是规范形式（所以「打开就保存」不产生
无谓改动）、渲染 → 再载入的数据必须一字不差、渲染必须幂等、每个编辑操作改的都是该改的地方、
「重新载入」是真的重新从磁盘导入。`tests/run-tests.ps1` 第 0 步会顺带跑它。

游戏那边的测试是 `tests/test_guide_demos.gd`（91 项）：帧数据能不能解出来、文字有没有写、
棋子与箭头在不在棋盘里、相邻帧重不重复、画布范围与逐帧缩放对不对、控件能不能播。
**它不再核对棋规**——那是这次改成纯动画之后主动放弃的保护。

## 手写剧本时的那道「剧本区」标记

每个 `tools/demos/*.py` 长这样：

```python
# -*- coding: utf-8 -*-
"""大段说明：为什么这么摆位、这个坑怎么来的……（编辑器和导出器都不动这一段）"""

from guide_demo_kit import Demo, Frame, red, green, arrow

SYMBOL = "王"

# --- 剧本区开始：以下由 tools/editor 改写（手改这里的格式会在下次保存时被覆盖）---
def demos():
    return [
        Demo(...),
    ]
# --- 剧本区结束 ---
```

* **标记以上**是你手写的地方：说明文档、import、`SYMBOL`。编辑器保存时原样留着。
* **标记之间**是数据：编辑器会整段重写，所以别在这里写注释或辅助函数
  （要写就把话挪到文件开头的 docstring 里）。
* 编辑器顺带会把 `from guide_demo_kit import …` 那一行补齐（只保留这个库真有的名字），
  不然给某个兵种加一段带箭头/高亮的动画时，生成的模块一 import 就 `NameError`。
